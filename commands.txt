# DOCKER
1. docker build -t myimage:v1 . -----–> Builds a Docker image from a local Dockerfile in your current directory.
2. docker tag myimage:v1 username/myrepo:v1 –-----> Prepares your local image for a remote registry by renaming it with your account details.
3. docker login –-----> Authenticates your session with your remote Docker Hub username and password.
4. docker push username/myrepo:v1 –-----> Uploads your completed local image to the remote repository.
5. docker pull username/myrepo:v1 –-----> Downloads a fresh copy of the image from the remote repository to your current machine.
6. docker run -d -p 8000:80 --name myweb nginx –----> Creates and starts a container from an image in the background with mapped network ports.
